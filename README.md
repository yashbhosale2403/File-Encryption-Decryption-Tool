# 🔐 File Encryption/Decryption Tool

A simple Python tool to **encrypt and decrypt text files** using the `cryptography` library and a secret key. This tool helps you securely store and transfer sensitive files.

---

## 🛠 Features

- Generate and save a secure encryption key (`secret.key`)
- Encrypt any text or binary file using the generated key
- Decrypt previously encrypted files
- Simple command-line interface

---

## 📦 Requirements

- Python 3.6+
- `cryptography` library

### Install the required package:

```bash
pip install cryptography
